# SFLIX-20261120-011 – Desktop: BiB mit eigenem Symbol, Hauptfenster minimieren und wiederherstellen
- Erstellt am: 2026-11-20
- Absender: Planung
- Empfänger: Entwicklung
- Priorität: MEDIUM
- Status: COMPLETED
- Aufgabenbeschreibung: Im Desktop-Player (STEFFLIX.exe) öffnet BiB heute über requestPictureInPicture (player.js) ein WebView2-Fenster, das in der Taskleiste ohne Symbol erscheint. (1) Das BiB-Fenster soll ein eigenes Symbol bekommen: STEFFLIX-Logo mit einem kleinen Bild-in-Bild-Zeichen, im Code erzeugt wie app.ico (Branding.cs/AssetGen.cs, eingebettet über build.ps1) und dem BiB-Fenster zugewiesen (z. B. Fenster des WebView2-Prozesses suchen, WM_SETICON). (2) Bei jedem BiB-Start (Schaltfläche, Tastenkürzel, Kontextmenü) meldet player.js das dem Desktop (sendToDesktop), und das Hauptfenster minimiert sich, sodass nur das BiB-Bild sichtbar bleibt. (3) Wird BiB zurückgeführt (Zurück-zum-Player), öffnet sich das Hauptfenster im vorherigen Zustand (normal, maximiert oder Vollbild), im Vordergrund, Player läuft weiter. (4) Wird BiB mit dem X geschlossen, bleibt das Hauptfenster minimiert (Wiedergabe gestoppt, Benutzer will etwas anderes tun). Der Browser meldet in beiden Fällen nur leavepictureinpicture: Unterscheidung selbst finden (z. B. Chromium pausiert beim X das Video, beim Zurückführen nicht) und im Test belegen. Im normalen Browser und in der Android-App bleibt BiB unverändert.
- Technischer Kontext: Benutzerentscheide vom 20.11.2026 (siehe DEC zu BiB im Desktop). BiB-Code in player.js um Zeile 2030-2045, WebMessage in PlayerForm.cs OnWebMessage (Zeile 270).
